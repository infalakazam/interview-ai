PrepAI project guide: README.md

The current Mohler scorer uses traditional ML (TF-IDF with scikit-learn regressors), and the app loads prepai_mohler_model.joblib through backend/app.py. Google sign-in is available after setting up a Web OAuth client ID.

You do not need to write backend code. After the one-time Google setup, double-click Start PrepAI API.bat to run the API.

For local steps, model details, Google Colab workflow, API instructions, adaptive difficulty, and the HCI/ML/SDLC presentation, read README.md.
